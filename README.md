# Replication package

Anonymised package for the paper *Selective Routing under Ownership Ambiguity: A Public Benchmark
and an Agent Study*, submitted for double-blind review. Nothing here identifies the authors; the
scan in the build script rejects the package if anything does.

## What this is

A benchmark of team-level bug routing built from the public Mozilla Bugzilla API, eight classical
baselines and three LLM conditions scored by one evaluator, and the analysis behind every number and
table in the paper.

## Layout

| Path | Contents |
|---|---|
| `code/` | every script: data collection, dataset construction, label cleaning, baselines, the LLM conditions, the evaluator, the table and figure generators, the consistency checks |
| `data/components.json` | the BMO component-to-team mapping the labels depend on |
| `data/dataset_labeled.jsonl` | the processed dataset, with the ownership category of every bug |
| `results/` | metrics, every prediction file, the LLM transcripts, the significance tests, the cost audit |
| `paper/` | LaTeX source, generated tables, figures, bibliography |

The raw Bugzilla pulls are not included: they are 190 MB, they are regenerated by
`code/fetch.py`, and the API changes over time so a re-fetch is not byte-identical anyway. The
processed dataset above pins the exact rows the paper used.

## Reproducing the numbers

Python 3.12, then:

    python -m venv .venv
    .venv/Scripts/pip install -r code/requirements.txt     # .venv/bin/pip on Linux, macOS

    .venv/Scripts/python code/score_all.py                 # metrics for every prediction file
    .venv/Scripts/python code/significance.py --split test2026
    .venv/Scripts/python code/agent_vs_baseline.py --split test2026
    .venv/Scripts/python code/make_figures.py
    .venv/Scripts/python code/make_tables.py --split test2026
    .venv/Scripts/python code/check_paper.py
    .venv/Scripts/python code/spend_report.py

Every table in the paper is written by one of those scripts into `paper/tables/`, and the prose
quotes its figures through macros generated from the same run, so the text cannot drift from the
tables.

## Rebuilding the PDF

    cd paper && ..\.venv/Scripts/python build.py

The build stages the bibliography and runs Tectonic. Any full TeX distribution with `pdflatex`
works too.

## Re-running the LLM conditions

This costs money and is **not** required to check the paper's claims: the transcripts in `results/`
are the record, and `score_all.py` recomputes every metric from them. If you do re-run, set
`DEEPSEEK_API_KEY` in the environment; every request is cached on disk by its payload hash, so a
repeat of an already-run bug costs nothing.

    .venv/Scripts/python code/run_llm.py --condition agent --model deepseek-flash \
        --dataset data/dataset_all.jsonl --components data/components.json \
        --split test2026 --n 6347 --seed 0 --thinking disabled

## Verifying the labels

    .venv/Scripts/python code/verify_history.py      # re-fetches Bugzilla and diffs the stored history
    .venv/Scripts/python code/check_inbox_rule.py    # the ambiguous `::General` cases

## Notes

* The dataset is public Bugzilla data; no private or employer data is involved.
* The 150-bug manual review sample and its scores are in `results/manual_review_sample.csv` and
  `results/review_agreement.json`.
* The cost figures are estimates at recorded list prices, with the peak-hour multiplier applied per
  call; `results/spend_report.json` is the audit.
